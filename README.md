# Pixel Brake Zero

A mobile-first daily precision game. Ten taps, one shared daily challenge, no account and no download.

## Product loop

1. Start in one tap.
2. Stop the moving line on the target ten times.
3. Receive a compact, shareable result.
4. Return for the next daily run or practise immediately.

## Distribution target

- Primary: CrazyGames HTML5 submission after SDK integration and portal QA.
- Secondary: Poki playtest submission.
- Immediate testing: itch.io HTML5, r/playmygame and r/WebGames where current rules permit disclosed self-promotion.

The game is intentionally self-contained and runs from static files.
